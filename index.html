Cách Up Lên GitHub Pages & Gắn Link Lên Facebook

1 Thêm nhạc & Thông tin Chủ Nhân ngay trên trang này

Trong bảng 👑 Phòng Quản Trị Chủ Nhân, hãy điền Tên của bạn, Link Facebook cá nhân và thêm các bài hát bạn yêu thích (chọn file .mp3 từ máy hoặc dán link nhạc trực tiếp).

2 Bấm nút "Xuất File index.html Đã Khóa Playlist"

Khi bấm nút "Xuất File index.html Đã Nhúng Sẵn Playlist", hệ thống sẽ tải về cho bạn 1 file index.html mới đã chứa sẵn toàn bộ danh sách bài hát, tên của bạn, link Facebook của bạn và tự động khóa ở Chế Độ Khách Nghe Nhạc.

📁 Cấu trúc thư mục khi bạn up lên GitHub Repository:
├── 📄 index.html (File vừa xuất ra từ nút bấm)
├── 📄 playlist.json (Tùy chọn nếu muốn sửa nhanh danh sách bài hát)
└── 📁 music/ (Tạo thư mục tên là music và bỏ các file .mp3 của bạn vào đây)
├── 🎵 bai-hat-1.mp3
└── 🎵 bai-hat-2.mp3
3 Bật GitHub Pages & Gắn Link Lên Trang Cá Nhân Facebook
  • Vào kho chứa (Repository) trên GitHub của bạn → chọn mục Settings → Pages.
  • Tại phần Branch, chọn nhánh main (hoặc master) → bấm Save.
  • Sau 1 phút, GitHub sẽ cấp cho bạn đường link dạng: https://ten-ban.github.io/ten-repo/
  • Vào Trang cá nhân Facebook → Chỉnh sửa chi tiết công khai (Tiểu sử / Liên kết) → Thêm trang web và dán link GitHub Pages vào. Mọi người bấm vào chỉ có thể nghe nhạc và chỉnh EQ chứ không thể sửa hay xóa nhạc của bạn!
